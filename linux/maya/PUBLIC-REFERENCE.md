# Reference configuration

These are sanitized reference files, not an installed runtime. Obtain the pinned
sources/dependencies and weights separately, configure volume UUIDs and adapt
paths for your installation. Keep models, environments, API keys and private
harness state outside Git. Use both supported GPUs and retain memory guards.

Public profile copies require new local validation after path changes. Do not
copy the reference configuration fingerprint as proof for another machine.
The measurements describe the stated reference hardware and exact tested builds;
other hardware, compiler/library versions, quants and contexts need validation.
