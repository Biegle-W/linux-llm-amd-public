CPU PCIe4x8/x8. Purchased switch is not installed; direct P2P is disabled.

## Method and validation

Both profiles use 32,768 total context, both GPUs through layer groups, MTP,
40 GiB bounded expert RAM, automatic GPU caching, the same CPU settings and native
8 GiB reserves. Actual startup whole-card free must be at least 6 GiB on each
card; existing continuous latched RAM/VRAM guards, 52G worker scopes and zero
owned swap/spill remain. Each start used the same upstream expert seed. All five
tokenizer/template files are byte-identical across the quants.

The order is S24 → S → S → S24. Each start first passes arithmetic, JSON,
synthetic tool roundtrip, SSE, fresh 29,977-input retrieval and full-history
follow-up, then the shared benchmark. Code/prose use one excluded warm-up per
task and three timed requests, 256-output cap, temperature 0.6/top-p0.95/seed42,
thinking off. Fresh prefill uses the same three frozen salted record prompts,
greedy/64-output cap; their tokenized inputs are [6311, 6316, 6310] for BOTH
quants on every start and report zero prefix reuse. Native PP, external SSE TTFT
and external SSE decode are distinct measurements. Load/compilation are excluded.

All four starts passed the functional, dual-GPU and memory checks. These short
marker outputs do not prove general full-window quality, and no FP8 reference
quality score was measured locally. OS/page/expert caches and desktop activity
still evolve; six samples do not establish statistical significance or a universal
performance guarantee. The first cold S24 load was much longer than later
starts; per-start load times are retained rather than substituted for TTFT.

The native cache reports about 25.35 GB /3,804 GPU expert entries for S24 versus
23.71 GB /3,558 for S. Its higher-precision attention/shared weights leave fewer
experts cached. This is an observed allocation difference, not a controlled
isolation of attention-kernel cost versus cache-miss cost.

## Storage, retained setup and sources

Maya-S is the selected GLM quant; the S24 files are retained as rollback evidence, without adding another active profile. DeepSeek is unchanged.

The publisher revision is `f16ee4ba50d8fd2bb726ea1862ca6ca14ba188da` for both.
S24 is 94,701,676,224 bytes; S is 96,468,592,256 bytes. Three S shards were downloaded
to the shared NVMe and passed published SHA256; the native pack keeps experts
in GGUF in place. Its small dense/index/tokenizer assets were also fingerprinted.
[Exact optional S download manifest](../maya/glm-s-models.json).

independently recomputes the six-sample medians and gate. Raw logs and synthetic
answers remain private; no model weights, environments or runtime binaries are
published. See the [initial Maya batch](MAYA-2026-10-20.md) for unchanged DeepSeek
results and earlier three-trial S24 measurements, which remain historical.
