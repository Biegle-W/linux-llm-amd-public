# Frozen-design grader contract (red-team aligned)

`python3 grade_pub.py RESULTS ROUTE[,ROUTE...] --items ITEMS.jsonl --tier core|extended|all` writes graded.json schema 2. `python3 analyze.py RESULTS` writes analysis.json and analysis.md. Grade core and cumulative fast-only all in separate invocations/output directories (or preserve/rename prior reports); extended means extras alone and is exploratory, not the 300-item analysis.

Items accept the builder's grader string plus gold/meta, or inline grader objects. Supported kinds: mcq, numeric, tools, ifeval, code (unittest/assertions). Removed provisional grid/exact/stdin/functional grading: unsupported kinds are grader defects. Each result includes category, tier, source/stratum, binary correct, mutually exclusive status, and overlapping flags. Missing inference is pending, not an API error. Unavailable code isolation and grading-deadline omissions are ungraded; either condition makes the run incomplete. Grader defects halt statistical analysis. Capped rows always score zero; visible numeric/MCQ/IFEval/tool success is diagnostic only. Separate reasoning never rescues the answer.

MCQ/math: strip complete think blocks and unclosed reasoning suffixes; orphan closing think delimiters discard the prefix as reasoning. Last explicit ANSWER:/Final answer: marker wins even when malformed, before last box and whole bare scalar. No free-standing-letter/number mining from prose. Math parses exact rational values and candidate decimal/scientific notation, valid comma grouping, leading zeros and LaTeX frac/dfrac/tfrac. Only explicit numeric finals permit benign punctuation, ordinal suffix and the frozen NUMERIC_UNITS allowlist, including day/days. Extraction path is recorded. Raw IFEval and code interiors are not cleaned.

IFEval: 10 supported IDs are declared in grade_pub.SUPPORTED_IFEVAL. Source-audited official check_following semantics are pinned to google-research commit e6890f85757dd84e27ca6df2dd30651dafad28e0, instruction_following_eval/instructions.py, SHA256 60e086f5342a03ce8e18b64bbcccf86308f523c08aa826707a562150a52f3edf. The fetched master and pinned copies matched byte-for-byte. English capital/lowercase IDs require langdetect, and number_words requires non-stdlib tokenization; all three are excluded, not approximated. Builder MUST remove them before freezing and still meet the 44-item quota. Full official dependency-based integration parity was not executed; no downloaded Python source was executed.

BFCL: only structured calls earn call-requiring success. Exact multiset assignment uses backtracking, preserves nested value types recursively (including bool versus int), rejects extra parameters/calls, and accepts omission only for gold's explicit empty-string sentinel. Irrelevance needs nonempty completed stop content and no calls. A selftest covers builder question[0] preservation, recursive schema conversion and reversible function-name normalization.

Code isolation: set PUB_SANDBOX_IMAGE to a trusted locally present Python 3.14 image pinned as repository@sha256:<64 lowercase hex>. The grader never pulls images. It creates a fresh container per candidate/reference call, verifies inspect configuration BEFORE start, then uses nonroot UID/GID 65534, network none, read-only root, no host mounts, dropped capabilities, no-new-privileges, 512 MiB memory, pids cap, a disposable /work tmpfs, python3 -I, CPU 5 s, execution wall 10 s and 1 MiB output/file limits. No stdin is exposed to candidate code. Audit denial is defense in depth only. Docker config failure leaves the item ungraded, never locally executes it. Trusted tests must execute at least one non-skipped unittest or assertion. Successful details record image digest and test count. Docker daemon was UNAVAILABLE locally (socket absent); actual container execution, Linux hostile-code behavior and reference baselines remain NOT VERIFIED. Offline tests verify refusal/mocked dispatch, not an independently audited secure sandbox.

validate_reference(code,spec,temp_root) is a preflight helper requiring three fresh passes and rejecting failures/flakiness or >=8 s wall-borderline runs; missing isolation returns None (fatal preflight, not item exclusion). Builder integration must use three reference runs; see GRADER_ALIGNMENT.md.

Deadline: when RESULTS/fleet.json exists, grading automatically derives the remaining 20 h budget from fleet_start and max_elapsed_seen. A monotonic deadline freezes the remaining budget within the invocation. --deadline-monotonic can impose a stricter cutoff. Code launches reserve 50 s for create/inspect/execution/cleanup; unfinished items remain ungraded. Backend draining and the outer physical deadline remain chair responsibilities.

Statistics: report failures in the fixed denominator, but never turn pending into intended ranking outcomes. Incomplete primary scores/CIs are null; JSON includes explicitly diagnostic pending-as-zero and completed-only accuracy. Pairwise incomplete analysis uses the identical completed IDs across all supplied routes and labels it exploratory. Full 12-route 216-item core uses the 66-pair Holm family; eight-route 300-item cumulative fast analysis uses a secondary 28-pair family. Manifest and per-route hashes must match for confirmatory labeling. Exact McNemar, <=.05 Holm rule, Wilson z=1.959963984540054, and paired SOURCE/STRATUM (not category-only) bootstrap follow DESIGN. Seed is exactly 20261110|bootstrap|lexicographically_smaller_route|larger_route|tier, 10,000 draws, prescribed floor/ceil order-statistic endpoints. Raw p, adjusted p, paired counts, exact paired IDs, usage and source strata are retained. Optional combined 94-hypothesis correction is not implemented (the design calls it optional).
