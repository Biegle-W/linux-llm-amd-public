# Hy4-Flash SQ-64 on Strata 0.2.18 — November 22, 2026

The owner pointed out that Strata 0.2.18 can run Tencent's 220B Hy4-Flash and asked for the SQ-64 pack to be set up. It runs. It is a trial on a side install, not a hub route: while it is loaded it holds almost all of the machine's RAM, so nothing else can load. Every figure is from one short session; none is a sustained benchmark.

## Result

| | |
|---|---|
| Model | Tencent Hy4-Flash, 220B parameters (63.5B of them a lookup table that stays on disk), about 12B active per token |
| Pack | Strata's SQ-64: 62.0 GB model file, 67.6 GB lookup table, 0.9 GB vision file; 130 GB on the streaming NVMe drive |
| Engine | `strata-hy4` 0.1.64 from the Strata 0.2.18 release (official RX 7900 package, built at `6e38f588a646`), with Strata's own server from the same source |
| Load | 50 s |
| Decode | 26–30 tok/s (26.2 on a 400-token answer, 23.6 after a 6,624-token prompt) |
| Prompt read | 1,146 tok/s on a 6,624-token prompt |
| Context | 32,768 (the default 131,072 needs about 4 GB more RAM than the machine has spare) |
| RAM | the engine holds 53–54 GB; 4.1–4.4 GB of 61.5 GB left available throughout; swap did not grow |
| VRAM | 24.3 GB on the second card (0.5 GB free); the display card is not used |

How it runs here: the engine put 271 experts permanently and 3,685 in adaptive slots on the card (14.7 GB) and kept 20,720 experts (55.0 GB) in RAM, computed by ten CPU threads. The second card gets nothing: on AMD this engine uses one card. The drafter was on and accepted about 0.9 drafted tokens per step.

## Quick quality test (its first real run)

| Block | Result | Time |
|---|---:|---:|
| Harness tasks, core | **12 of 12** | 5.4 min |
| Harness tasks, extra | 8 of 8 | 2.8 min |
| Function calls (B) | 9 of 16 | 2.0 min |
| General (C-core) | 5 of 10 | 0.8 min |

The whole test took 11 minutes against the 60 allowed. In the harness the model averaged 3.7 tool calls per task with no rejected call and no task stopped by a limit. With thinking off it answers the general items in a handful of tokens, which is why that block took under a minute.

For comparison, the same 26 shared items rescored from the saved runs of existing routes (not rerun): function calls 8–14 of 16 and general 3–10 of 10, for example Flash-Next 9 and 7, DeepSeek on Maya 12 and 10, GLM 12 and 4, Inkling 10 and 4. Hy4-Flash at 9 and 5 is in the middle of that range. With 26 items this does not rank it; the 216-item suite was not run, under the owner's rule.

What the first run showed about the test itself:
- **All 20 harness tasks passed.** Either this model is strong at harness tool use or the tasks are too easy to separate good models; one model cannot tell which. The next new model will.
- **The harness prompt was not cached between steps on this engine** (0 cached tokens reported, 421,583 prompt tokens read in 8.2 minutes). It did not matter at 1,146 tok/s, but on an engine that reads at 35–110 tok/s the same test would not fit its budget without a cache.
- The jail, the per-task limits and the graders worked as built; nothing needed changing.

## Why it is not a route yet

- **RAM.** 61.5 GB is below the author's stated 64 GiB minimum. It ran with about 4 GB to spare at 32K context and nothing else loaded. A desktop application that takes a few gigabytes while it is loaded could push it into swap or get it stopped by the system's memory guard.
- **One card, CPU-bound.** Decode is set by the i5-13600KF, not by the cards.
- **A day-old engine.** Upstream has open reports of an endless repetition loop on long reasoning with this pack and of tool-call drift being largest on SQ-64; neither was seen in this short session, and neither was tested for.
- **Publisher's own numbers** put Hy4-Flash behind Qwen3.8-Flash-Next, DeepSeek V4.1 Flash and GLM 5.3 Flash on coding and terminal work, and level or ahead on office and tool-automation tasks.

The alternative for this hardware is Maya's Hy4 engine (now installed with Maya 1.1.73), which uses both cards and splits a smaller pack across RAM and VRAM; it needs a separate 110–118 GB download. That was tested the same day with Maya-M: it frees the RAM but is no faster ([report](HY4-FLASH-MAYA-M-2026-11-22.md)).

- Pack: the streaming NVMe drive, folder `LLM-Models/Hy4-Flash-Strata` (14% of that drive used).
