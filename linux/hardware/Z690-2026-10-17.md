> The initial motherboard smoke measurements below predate that tuning.

Linux identifies an MSI MPG Z690 CARBON WIFI (MS-7D30), two RX 7900 XTX cards
with 24,560 MiB usable VRAM each, and approximately 30.6 GiB OS-usable RAM
(32 GB installed). The additional 32 GB RAM is still pending. Keep all model
weights GPU-resident and leave Strata inactive until the RAM upgrade is completed
and its dual-HIP model profile is validated.

## Later P2P investigation

The kernel explicitly rejects the cross-root GPU path. Intel documents no P2P
memory reads/writes for the 13600KF's graphics ports; HIP stays false in both
directions under process-local fine-grain PCIe settings. See the
[P2P diagnosis and proposed active-switch remedy](PCIE-P2P-2026-10-17.md).
The switch is not installed or validated. Production host transport is retained.

## GPU topology

Both GPU paths now reach separate CPU PEG root ports at PCIe 4.0 x8. The old
CPU x16 plus chipset x4 arrangement no longer applies. Each GPU's internal link
still reports x16; the upstream x8 links are the relevant limits.
ROCm identifies both gfx1100 cards and reports **no peer access in either
direction**. Do not claim that a new motherboard automatically enables ROCm P2P
or that every workload is faster.

Both-card placement remains mandatory: llama.cpp Vulkan layer split 1:1;
SGLang/vLLM ROCm TP2. Device discovery handled the changed PCI addresses without
launcher edits. The existing isolated no-hostcall RCCL library, P2P-disabled and
SDMA-disabled settings were retained. Two-rank FP32/BF16 all-reduce and all-gather
passed at 1, 4,096 and 1,048,576 elements. Stock RCCL and alternative transport
settings were not compared on this motherboard.

## SGLang MTP restored

`qwen3.8-27b-sglang` now passes startup, arithmetic, ordered JSON and a complete
tool-call/result exchange on both cards. It is enabled again in DSH, Turnstone
and the API catalog. Settings: 40,960 total-token budget and reported cache
capacity, GPTQ W4A16, MTP2, BF16 KV, graph execution, prefix caching disabled,
static memory fraction 0.85 and 21 GiB free-VRAM guard on each card.
The retained KV bounds-trap and MTP-sharing patches remain in place.
The motherboard change is associated with the successful retry; this is not
an isolated experiment proving the cause of every prior failure.

configuration now binds the discovered address; its existing bearer key and
